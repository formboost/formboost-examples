# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security issue affecting Formboost or one of the official examples, contact the Formboost team through the official support channel listed at https://formboost.app.

Please include enough detail for the issue to be reproduced without sharing production credentials, secrets, payment information, or real customer submission data.

## Example repository safety

Official examples must never contain:

- Production API keys or credentials
- Private access tokens
- Payment details
- Real customer submission data
- Internal infrastructure secrets

Use placeholders and `.env.example` files where configuration is required.
